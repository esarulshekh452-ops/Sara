LuvuBox Image → JSON

Turn any picture into a single-frame OLED image animation you can save as JSON and upload to your LuvuBox animation library.

1. Choose and fit your picture

LuvuBox monochrome screens display pixels as black or white. Dithering can preserve more detail in photos.

2. OLED preview

This exports exactly one frame, so it behaves like a still image. Frame time is included for firmware compatibility.

Choose an image to begin.

3. Export LuvuBox JSON

The converter automatically simplifies the picture to fit the firmware's limit of 40 drawing operations per frame. Very detailed images may lose some detail.

Output uses the LuvuBox custom-animation format: name, frameMs, and frames with drawing operations. Keep the exported file as a .json file.
